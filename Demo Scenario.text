3. GIỚI THIỆU PIPELINE (2 phút) — SLIDE HOẶC NÓI MIỆNG
================================================================================

Lời dẫn:
"Đồ án xử lý end-to-end trong Jupyter Notebook:

  Dữ liệu thô (dataset.csv)
    → EDA & làm sạch
    → Chi-square: bỏ 4 biến không liên quan Target
    → Chuẩn hóa StandardScaler
    → PCA 10 chiều + K-Means 3 cụm → 11 đặc trư

       Random Forest, XGBoost, LightGBM, CatBoost

Mô hình deploy (thường XGBoost) được lưu vào model.pkl.
Ứng dụng Streamlit chỉ load file này — không train lại trên web."

|-----------|----------------------------|

| Export | Phụ lục C |

import pickle

pipeline = {
    "model": xgb_model,
    "label_encoder": le,
    "feature_cols": list(X_after_chi2.columns),
    "scaler": scaler,
    "pca": pca,
    "kmeans": kmeans,
}

with open("model.pkl", "wb") as f:
    pickle.dump(pipeline, f)

print("✅ Đã lưu model.pkl")
print("   feature_cols:", len(pipeline["feature_cols"]), "cột")
print("   Chạy web: streamlit run app.py")
